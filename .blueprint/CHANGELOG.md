# Histórico de versões do Blueprint

> **Para que serve:** resume mudanças herdáveis entre versões publicadas para que projetos derivados avaliem atualizações sem depender do histórico completo de commits.

O formato segue [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e as versões seguem SemVer. Mudanças ainda não publicadas ficam em **Não publicado**.

## Não publicado

Nenhuma mudança registrada.

## 0.1.0 — 2026-08-06

### Adicionado

- Governança por issue, Project, branch temporária, PR, Rulesets e auto-merge controlado.
- Bootstrap assistido e retomável para projetos derivados.
- Políticas canônicas de workflow, segurança, engenharia e consistência transversal.
- Contexto obrigatório de visão e engenharia específico do projeto.
- Templates de issues, PRs, ADRs, ideias e revisão.
- Validações locais e GitHub Actions para estrutura, documentação e rastreabilidade.
- Versionamento por tags SemVer e criação controlada de GitHub Releases.
- Guia de início ponta a ponta no README.
- Verificação sob demanda da versão do Blueprint em projetos derivados.
- Manifesto de propriedade para arquivos gerenciados, assistidos e locais.
