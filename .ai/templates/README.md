# Templates textuais

> **Para que serve:** reúne modelos que podem ser copiados para o artefato oficial apropriado sem apresentar exemplos fictícios como decisões reais.

- `idea.md`: síntese de descoberta antes do refinamento.
- `adr.md`: proposta e registro de decisão arquitetural material.
- `review-report.md`: parecer de revisão de um pull request.

Issues implementáveis, pesquisas e documentação usam os formulários em `.github/ISSUE_TEMPLATE/`. Pull requests usam `.github/pull_request_template.md`.

Conteúdo entre `<...>` é instrução de preenchimento e deve ser removido no artefato criado. Os próprios templates não contam como placeholders do bootstrap.
