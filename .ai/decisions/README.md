# Decisões arquiteturais

> **Para que serve:** explica quando registrar uma decisão durável como ADR. Esta pasta começa sem ADRs para não apresentar exemplos como decisões reais do projeto.

## Quando criar

Crie ADR apenas para decisão estrutural, transversal, difícil de reverter ou com consequências relevantes de longo prazo. Preferência local, escolha trivial e detalhe facilmente reversível pertencem à issue ou ao PR.

## Convenção

Use `NNNN-titulo-curto.md`, começando por `0001`. ADRs aceitas não são reescritas para apagar o histórico; uma nova ADR as substitui quando necessário.

## Template

Copie [`.ai/templates/adr.md`](../templates/adr.md) para esta pasta, renomeie-o e substitua todos os campos indicados.
